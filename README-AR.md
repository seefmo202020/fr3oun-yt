# Fr3oun AI v0.2

لوحة عربية لإعداد فيديوهات YouTube: توليد عنوان ووصف وTags وهاشتاجات عبر Gemini، توليد صورة مصغرة (إذا كان موديل الصور متاحاً لمفتاحك)، رفع صورة من جهازك، وربط قناة يوتيوب عبر Google OAuth ثم رفع الفيديو.

## التشغيل على استضافة Node.js
- Runtime: Node.js 18 أو أحدث
- Build command: `npm install`
- Start command: `npm start`
- Root directory: اتركه فارغاً إذا رفعت محتويات هذا المجلد إلى جذر المشروع.
- لا ترفع ملف `.env` أو `token.json` إلى GitHub.

## متغيرات البيئة المطلوبة
انسخ القيم من `.env.example` إلى Environment Variables في لوحة الاستضافة:
- `GOOGLE_CLIENT_ID`
- `GOOGLE_CLIENT_SECRET`
- `GOOGLE_REDIRECT_URI` (الرابط العام للموقع متبوعاً بـ `/oauth2callback`)
- `GEMINI_API_KEY`

المتغيرات الاختيارية:
- `GEMINI_TEXT_MODEL` (الافتراضي `gemini-2.5-flash`)
- `GEMINI_IMAGE_MODEL` (الافتراضي `gemini-2.0-flash-preview-image-generation`)

## إعداد ربط يوتيوب
1. أنشئ مشروعاً في Google Cloud Console وفعّل YouTube Data API v3.
2. جهّز OAuth consent screen.
3. أنشئ OAuth Client ID من نوع Web application.
4. أضف رابط `https://YOUR-DOMAIN/oauth2callback` إلى Authorized redirect URIs.
5. ضع Client ID وClient Secret وRedirect URI في متغيرات البيئة.
6. اضغط Connect YouTube داخل الموقع ووافق على الصلاحيات.

قد تحتاج Google إلى مراجعة التطبيق أو إضافته كمستخدم اختبار أثناء وضع Testing. لا تضع كلمة مرور Google في الموقع.

## إعداد Gemini
أنشئ مفتاح Gemini API من Google AI Studio وضعه في `GEMINI_API_KEY`. توافر النماذج وحدود الاستخدام والتكلفة تختلف حسب الحساب والمنطقة؛ لا توجد ضمانة أن توليد الصور متاح مجاناً. إذا لم يعمل نموذج الصور، غيّر `GEMINI_IMAGE_MODEL` إلى نموذج صور متاح لحسابك.

## ملاحظات مهمة
- الموقع لا يضمن تصدر نتائج البحث؛ الاقتراحات مبنية على الموضوع الذي تدخله.
- في هذه النسخة، تحليل الفيديو لا يتم من محتوى الملف نفسه: اكتب ملخصاً دقيقاً لمحتواه في خانة الموضوع ليتم توليد بيانات مناسبة. استخراج محتوى الفيديو تلقائياً ميزة لاحقة.
- الصورة المولدة أو المرفوعة تُعيّن بعد نجاح رفع الفيديو. إذا فشل تعيين الصورة، سيظل الفيديو مرفوعاً ويمكن ضبط الصورة لاحقاً من YouTube Studio.
- الملفات المؤقتة ورمز OAuth محفوظة محلياً في مجلد التطبيق. إذا كانت الاستضافة تمسح الملفات عند إعادة التشغيل أو لا توفر تخزيناً دائماً، قد تحتاج إعادة ربط القناة. استخدم تخزيناً دائماً/آمناً في الإنتاج.
- يرفع الفيديو عبر YouTube API؛ حدود حجم/مدة الفيديو والحصة اليومية تخضع لسياسات YouTube API والحساب.
- هذه نسخة أولية تحتاج اختباراً على الاستضافة قبل الاعتماد عليها للنشر الفعلي.
